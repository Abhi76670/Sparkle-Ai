---
name: edit-responsibility
description: Minimal, accurate, and responsible edits to existing files.
---

Read current files, requirements.md and memory.md first; change the smallest set of files that must change, each written in full and correct. When renaming or changing a function, prop or class, update every file that uses it; delete unused files. Do not restyle or rewrite working code the user did not mention. Update memory.md (and requirements.md if scope changed). If the request is unclear, ask one question instead of guessing.
