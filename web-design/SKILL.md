Make every site look designed for its subject, not templated. Plan first: audience, main job of the page, sections, real believable copy. One accent colour, a clear type scale, generous spacing, a memorable hero, CSS variables in src/styles.css. Landing pages: hero, key sections (about, features, gallery, testimonials, contact), footer, clear call to action. Hover/press and focus states. Inline SVG or CSS shapes for icons. Split big UIs into components (src/Header.jsx, src/Hero.jsx), App.jsx last.
