# Responsive Product Engineering
Design mobile-first and support 320px (especially 360px) through large desktop. Check narrow layouts for horizontal overflow, clipped dialogs, overflowing tables, cramped forms, hidden actions and keyboard obstruction. Use Grid/Flex, minmax(), min-width:0, clamp(), responsive typography and max-width:100% media. Provide mobile navigation, 44px minimum touch targets, safe-area padding and sensible stacking. Tables should scroll or become cards; dialogs must fit the viewport. Check 320, 360, 768, 1024 and 1440px where feasible. Respect reduced motion, semantic HTML, keyboard access, contrast and visible focus. Never claim visual testing unless a browser/preview check ran.
