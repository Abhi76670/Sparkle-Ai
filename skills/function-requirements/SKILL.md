---
name: function-requirements
description: Detailed specification for every function or feature.
---

For every function or feature work out: purpose, inputs (type, validation), output, state and storage touched, edge cases (empty, invalid, duplicate, very long), error and success messages, dependencies. Put the list in requirements.md under the feature name, then implement all of it. If the user asks what is required for X, answer with this list and do not build.
