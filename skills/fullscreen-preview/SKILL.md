# Full Screen Code and Preview
- Provide a dedicated full-screen code view for long code blocks.
- Provide a separate full-screen live preview that uses the full viewport and hides surrounding editor/terminal chrome.
- Preserve the normal compact preview as the default; full-screen mode must be reversible with an obvious close control.
- Ensure controls remain touch-friendly and work on narrow mobile screens.
